# 1.5 Convert Listeners to Event Emitters

## Objective
Modify existing backend listeners to broadcast events via WebSocket instead of (or in addition to) calling UI callbacks directly.

## Duration
**3-4 hours**

## Prerequisites
- Completed [1.4 Design Protocol](1.4-protocol-design.md)
- Understanding of existing listener interfaces (IBotStateListener, IQueueStateListener, etc.)
- Access to wos-serv code

---

## Current Listener Architecture

Existing listeners in wos-hmi:
```java
// LauncherActionController.java
public class LauncherActionController implements IBotStateListener, IQueueStateListener {
    @Override
    public void onBotStateChange(DTOBotState botState) {
        Platform.runLater(() -> layoutController.onBotStateChange(botState));
    }

    @Override
    public void onQueueStateChange(DTOQueueState queueState) {
        Platform.runLater(() -> layoutController.onQueueStateChange(queueState));
    }
}
```

These listeners are registered with backend services:
```java
ServScheduler.getServices().registryBotStateListener(this);
ServScheduler.getServices().registryQueueStateListener(this);
```

---

## Strategy

Instead of calling UI directly, backend should broadcast events via WebSocket. We'll:
1. Create WebSocket event broadcaster
2. Register broadcaster as listener in backend
3. Keep existing listeners working (backward compatibility during Phase 1)

---

## Implementation

### 1. Create Event Broadcaster

**File:** `wos-api/src/main/java/cl/camodev/wosbot/api/server/EventBroadcaster.java`

```java
package cl.camodev.wosbot.api.server;

import cl.camodev.wosbot.api.protocol.Event;
import cl.camodev.wosbot.ot.DTOBotState;
import cl.camodev.wosbot.ot.DTOLogMessage;
import cl.camodev.wosbot.ot.DTOQueueState;
import cl.camodev.wosbot.serv.IBotStateListener;
import cl.camodev.wosbot.serv.IQueueStateListener;
import cl.camodev.wosbot.serv.IStaminaChangeListener;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.HashMap;
import java.util.Map;

/**
 * Listens to backend events and broadcasts them via WebSocket.
 */
public class EventBroadcaster implements IBotStateListener, IQueueStateListener, IStaminaChangeListener {
    private static final Logger logger = LoggerFactory.getLogger(EventBroadcaster.class);

    private final WebSocketSessionManager sessionManager;
    private final ObjectMapper objectMapper = new ObjectMapper();

    public EventBroadcaster(WebSocketSessionManager sessionManager) {
        this.sessionManager = sessionManager;
    }

    // ==================== Bot State ====================

    @Override
    public void onBotStateChange(DTOBotState botState) {
        logger.debug("Broadcasting botStateChanged event");
        broadcastEvent("botStateChanged", botState);
    }

    // ==================== Queue State ====================

    @Override
    public void onQueueStateChange(DTOQueueState queueState) {
        logger.debug("Broadcasting queueStateChanged event");
        broadcastEvent("queueStateChanged", queueState);
    }

    // ==================== Stamina ====================

    @Override
    public void onStaminaChanged(Long profileId, int newStamina) {
        logger.debug("Broadcasting staminaChanged event for profile {}", profileId);
        Map<String, Object> data = new HashMap<>();
        data.put("profileId", profileId);
        data.put("stamina", newStamina);
        broadcastEvent("staminaChanged", data);
    }

    // ==================== Log Messages ====================

    /**
     * Broadcast log message (called manually, not via listener interface)
     */
    public void broadcastLogMessage(DTOLogMessage logMessage) {
        logger.debug("Broadcasting logMessage event");
        broadcastEvent("logMessage", logMessage);
    }

    // ==================== Generic Broadcast ====================

    /**
     * Broadcast event to all connected clients.
     */
    private void broadcastEvent(String eventName, Object data) {
        try {
            Event event = new Event(eventName, data);
            String json = objectMapper.writeValueAsString(event);
            sessionManager.broadcast(json);
        } catch (Exception e) {
            logger.error("Failed to broadcast event: {}", eventName, e);
        }
    }

    /**
     * Register this broadcaster with backend services.
     */
    public void registerWithBackend() {
        logger.info("Registering event broadcaster with backend services");

        cl.camodev.wosbot.serv.impl.ServScheduler scheduler =
            cl.camodev.wosbot.serv.impl.ServScheduler.getServices();

        scheduler.registryBotStateListener(this);
        scheduler.registryQueueStateListener(this);

        cl.camodev.wosbot.serv.impl.StaminaService staminaService =
            cl.camodev.wosbot.serv.impl.StaminaService.getServices();

        staminaService.addStaminaChangeListener(this);

        logger.info("Event broadcaster registered successfully");
    }
}
```

### 2. Update BotWebSocketServer

Modify `BotWebSocketServer.java` to create and register the broadcaster:

```java
public class BotWebSocketServer {
    // ... existing fields ...
    private EventBroadcaster eventBroadcaster;

    public void start() throws Exception {
        logger.info("Starting WebSocket server on port {} with path {}", port, path);

        // Initialize components
        sessionManager = new WebSocketSessionManager();
        messageDispatcher = new MessageDispatcher();

        // Create and register event broadcaster
        eventBroadcaster = new EventBroadcaster(sessionManager);
        eventBroadcaster.registerWithBackend();

        // ... rest of start() method ...
    }

    public void stop() throws Exception {
        logger.info("Stopping WebSocket server...");
        sessionManager.closeAll();
        // Event broadcaster will be automatically unregistered via listener removal
        if (server != null) {
            server.stop();
        }
        logger.info("WebSocket server stopped");
    }
}
```

### 3. Test Event Broadcasting

**Test steps:**

1. Start WebSocket server
2. Connect client via wscat
3. Trigger backend event (e.g., start bot)
4. Verify event is received by client

**Test script:** `test-events.sh`

```bash
#!/bin/bash

echo "Starting test..."
```

**Expected output when bot starts:**

## Testing Checklist

Test each listener type:

### Bot State Events
- [ ] Start bot → receive `botStateChanged` event (running: true)
- [ ] Stop bot → receive `botStateChanged` event (running: false)
- [ ] Pause bot → receive `botStateChanged` event (paused: true)
- [ ] Resume bot → receive `botStateChanged` event (paused: false)

### Queue State Events
- [ ] Queue starts → receive `queueStateChanged` event
- [ ] Queue pauses → receive `queueStateChanged` event
- [ ] Queue resumes → receive `queueStateChanged` event

### Stamina Events
- [ ] Stamina changes → receive `staminaChanged` event with profileId and new value

### Multiple Clients
- [ ] Connect two clients
- [ ] Trigger event
- [ ] Both clients receive event

## Troubleshooting

### Events not received by client
**Check:**
- Is EventBroadcaster registered? (check logs)
- Is client connected? (check session count)
- Are events being triggered? (add debug logs)

### JSON serialization errors
**Solution:** Add `@JsonIgnore` to problematic DTO fields:
```java
@JsonIgnore
private transient SomeField field;
```

### Circular reference errors
**Solution:** Configure Jackson to handle circular refs:
```java
objectMapper.configure(SerializationFeature.FAIL_ON_SELF_REFERENCES, false);
```
