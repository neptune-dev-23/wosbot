# 1.4 Design Protocol

## Objective
Define formal message formats (Command, Event, Response) with proper schema, validation, and documentation.

## Duration
**2-3 hours**

## Prerequisites
- Completed [1.3 Build Service Facade](1.3-service-facade.md)
- Understanding of JSON structure
- Familiarity with Jackson annotations

---

## Protocol Overview

The API uses three message types:

1. **Command** (Client → Server): Request to perform action
2. **Response** (Server → Client): Result of command execution
3. **Event** (Server → Client): Unsolicited state update

## Implementation

### 1. Command Class

**File:** `wos-api/src/main/java/cl/camodev/wosbot/api/protocol/Command.java`

```java
package cl.camodev.wosbot.api.protocol;

import com.fasterxml.jackson.annotation.JsonProperty;

/**
 * Command message from client to server.
 *
 * Example:
 * {
 *   "id": "uuid-1234",
 *   "command": "startBot",
 *   "params": {}
 * }
 */
public class Command {

    @JsonProperty("id")
    private String id;

    @JsonProperty("command")
    private String command;

    @JsonProperty("params")
    private Object params;

    // Default constructor for Jackson
    public Command() {}

    public Command(String id, String command, Object params) {
        this.id = id;
        this.command = command;
        this.params = params;
    }

    // Getters and setters
    public String getId() { return id; }
    public void setId(String id) { this.id = id; }

    public String getCommand() { return command; }
    public void setCommand(String command) { this.command = command; }

    public Object getParams() { return params; }
    public void setParams(Object params) { this.params = params; }

    @Override
    public String toString() {
        return String.format("Command{id='%s', command='%s'}", id, command);
    }
}
```

### 2. Response Class

**File:** `wos-api/src/main/java/cl/camodev/wosbot/api/protocol/Response.java`

```java
package cl.camodev.wosbot.api.protocol;

import com.fasterxml.jackson.annotation.JsonProperty;

/**
 * Response message from server to client (in response to a Command).
 *
 * Success example:
 * {
 *   "id": "uuid-1234",
 *   "success": true,
 *   "result": { ... }
 * }
 *
 * Error example:
 * {
 *   "id": "uuid-1234",
 *   "success": false,
 *   "error": "Profile not found"
 * }
 */
public class Response {

    @JsonProperty("id")
    private String id;

    @JsonProperty("success")
    private boolean success;

    @JsonProperty("result")
    private Object result;

    @JsonProperty("error")
    private String error;

    // Default constructor
    public Response() {}

    private Response(String id, boolean success, Object result, String error) {
        this.id = id;
        this.success = success;
        this.result = result;
        this.error = error;
    }

    // Factory methods
    public static Response success(String id, Object result) {
        return new Response(id, true, result, null);
    }

    public static Response success(String id) {
        return new Response(id, true, null, null);
    }

    public static Response error(String id, String error) {
        return new Response(id, false, null, error);
    }

    // Getters and setters
    public String getId() { return id; }
    public void setId(String id) { this.id = id; }

    public boolean isSuccess() { return success; }
    public void setSuccess(boolean success) { this.success = success; }

    public Object getResult() { return result; }
    public void setResult(Object result) { this.result = result; }

    public String getError() { return error; }
    public void setError(String error) { this.error = error; }

    @Override
    public String toString() {
        if (success) {
            return String.format("Response{id='%s', success=true}", id);
        } else {
            return String.format("Response{id='%s', success=false, error='%s'}", id, error);
        }
    }
}
```

### 3. Event Class

**File:** `wos-api/src/main/java/cl/camodev/wosbot/api/protocol/Event.java`

```java
package cl.camodev.wosbot.api.protocol;

import com.fasterxml.jackson.annotation.JsonProperty;

/**
 * Event message from server to client (unsolicited state update).
 *
 * Example:
 * {
 *   "event": "botStateChanged",
 *   "data": {
 *     "running": true,
 *     "paused": false
 *   }
 * }
 */
public class Event {

    @JsonProperty("event")
    private String event;

    @JsonProperty("data")
    private Object data;

    @JsonProperty("timestamp")
    private long timestamp;

    // Default constructor
    public Event() {
        this.timestamp = System.currentTimeMillis();
    }

    public Event(String event, Object data) {
        this.event = event;
        this.data = data;
        this.timestamp = System.currentTimeMillis();
    }

    // Getters and setters
    public String getEvent() { return event; }
    public void setEvent(String event) { this.event = event; }

    public Object getData() { return data; }
    public void setData(Object data) { this.data = data; }

    public long getTimestamp() { return timestamp; }
    public void setTimestamp(long timestamp) { this.timestamp = timestamp; }

    @Override
    public String toString() {
        return String.format("Event{event='%s', timestamp=%d}", event, timestamp);
    }
}
```

## Protocol Documentation

### Command List

| Command | Parameters | Description |
|---------|-----------|-------------|
| `startBot` | None | Start bot (all enabled profiles) |
| `stopBot` | None | Stop bot (all profiles) |
| `pauseAllQueues` | None | Pause all profile queues |
| `resumeAllQueues` | None | Resume all profile queues |
| `pauseQueue` | `profileId: Long` | Pause specific profile queue |
| `resumeQueue` | `profileId: Long` | Resume specific profile queue |
| `getGlobalConfig` | None | Get all global configuration |
| `saveGlobalConfig` | `key: String, value: String` | Save config entry |
| `getProfiles` | None | Get all profiles |
| `getProfileById` | `profileId: Long` | Get specific profile |
| `getCurrentStamina` | `profileId: Long` | Get stamina for profile |
| `getStatus` | None | Get API/bot status |

### Event List

| Event | Data Type | Description |
|-------|-----------|-------------|
| `botStateChanged` | `DTOBotState` | Bot started/stopped/paused |
| `queueStateChanged` | `DTOQueueState` | Queue state updated |
| `staminaChanged` | `{profileId, stamina}` | Stamina changed for profile |
| `logMessage` | `DTOLogMessage` | New log message |
| `profileDataChanged` | `{profileId}` | Profile data modified |

## Example Messages

### 1. Start Bot
**Request:**
```json
{
  "id": "req-001",
  "command": "startBot",
  "params": {}
}
```

**Response:**
```json
{
  "id": "req-001",
  "success": true,
  "result": null
}
```

### 2. Get Profiles
**Request:**
```json
{
  "id": "req-002",
  "command": "getProfiles",
  "params": {}
}
```

**Response:**
```json
{
  "id": "req-002",
  "success": true,
  "result": [
    {
      "id": 1,
      "name": "Profile 1",
      "enabled": true,
      "priority": 10
    },
    {
      "id": 2,
      "name": "Profile 2",
      "enabled": false,
      "priority": 5
    }
  ]
}
```

### 3. Pause Specific Queue
**Request:**
```json
{
  "id": "req-003",
  "command": "pauseQueue",
  "params": {
    "profileId": 1
  }
}
```

**Response:**
```json
{
  "id": "req-003",
  "success": true,
  "result": null
}
```

### 4. Bot State Changed Event
**Event (no request):**
```json
{
  "event": "botStateChanged",
  "data": {
    "running": true,
    "paused": false
  },
  "timestamp": 1701531234567
}
```

### 5. Error Response
**Request:**
```json
{
  "id": "req-004",
  "command": "pauseQueue",
  "params": {
    "profileId": 999
  }
}
```

**Response:**
```json
{
  "id": "req-004",
  "success": false,
  "error": "Profile not found: 999"
}
```

## Unit Tests

**File:** `wos-api/src/test/java/cl/camodev/wosbot/api/protocol/ProtocolTest.java`

```java
package cl.camodev.wosbot.api.protocol;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

import java.util.Map;

public class ProtocolTest {

    private final ObjectMapper mapper = new ObjectMapper();

    @Test
    public void testCommandSerialization() throws Exception {
        Command cmd = new Command("test-123", "startBot", Map.of());
        String json = mapper.writeValueAsString(cmd);

        assertTrue(json.contains("\"id\":\"test-123\""));
        assertTrue(json.contains("\"command\":\"startBot\""));

        Command parsed = mapper.readValue(json, Command.class);
        assertEquals("test-123", parsed.getId());
        assertEquals("startBot", parsed.getCommand());
    }

    @Test
    public void testResponseSerialization() throws Exception {
        Response resp = Response.success("test-456", Map.of("key", "value"));
        String json = mapper.writeValueAsString(resp);

        assertTrue(json.contains("\"success\":true"));

        Response parsed = mapper.readValue(json, Response.class);
        assertTrue(parsed.isSuccess());
        assertEquals("test-456", parsed.getId());
    }

    @Test
    public void testEventSerialization() throws Exception {
        Event event = new Event("testEvent", Map.of("data", "test"));
        String json = mapper.writeValueAsString(event);

        assertTrue(json.contains("\"event\":\"testEvent\""));

        Event parsed = mapper.readValue(json, Event.class);
        assertEquals("testEvent", parsed.getEvent());
    }
}
```

Run tests:
```bash
mvn test -Dtest=ProtocolTest
```
